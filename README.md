# 字符物理实验

这是一个 React + Vite + TypeScript 的 Canvas 数字艺术实验，用程序化线稿复刻参考视频的视觉逻辑：

代码卡片默认使用 160 个可变字符，控制台允许在默认值上下各调整 60 个字符（100–220）。文字从卡片中间的一小处开始缺失和下沉，再按距离逐步影响周围，像建筑局部坍方向外扩散一样经历一段约 3.4 秒的可观察实时物理过程。每个字符被当作一块受空气作用的薄片来模拟：它会兜风、减速、打滑、翻转，并被一个无散度的涡旋场成团卷着走，而不是各自沿直线掉落。同列坍方模式保留整列缺口，传播粒度为单列连续泄露。当字符进入花丛高度后，才经过艺术指导式的状态替换成为蝴蝶。蝴蝶会被花朵吸引，依次接近、环绕、悬停并转访邻花，花园在 8 秒内完成生长。

## 启动

在 Windows PowerShell 中执行：

```powershell
cd "C:\Users\Administrator\Desktop\Character"
npm install
npm run dev
```

然后打开 Vite 输出的本地地址，默认是 `http://localhost:5173`。

## 结构

- `src/engine/types.ts`：粒子、蝴蝶、花朵和控制参数类型。
- `src/engine/scene.ts`：固定随机种子的场景引擎、固定步长调度和 Canvas 绘制。
- `src/engine/glyphPhysics.ts`：字形质量度量、无散度涡旋气流场和薄片气动积分。
- `src/engine/math.ts`：共享的 `clamp`、固定种子随机和缓动函数。
- `harness.html`：校准工装（仅开发服务器，不进入构建产物）。`?t=1.3,1.8,2.4&cols=3&scale=0.62` 抓帧与参考帧比对，`?check=1` 运行十二项自动检查，包含生态访花、代理帧率一致性和指针回归。
- `src/components/AnimationCanvas.tsx`：高 DPI Canvas、ResizeObserver 和 requestAnimationFrame 生命周期。
- `src/components/ControlPanel.tsx`：播放、时间轴、分组参数、蝴蝶轨道实验台、指针扰动实验台和恢复默认控制。
- `src/App.tsx`：React 状态与动画引擎之间的控制层。

## 设计说明

这个工程不使用原始视频作为背景，也不依赖原作者源码。字符、蝴蝶和花朵是三个独立对象，转换通过状态机和透明度交叉淡化完成。控制台的“文字变化形式”提供“局部扩散”“同列坍方”“中心聚拢”“波纹塌落”四种路径，默认局部扩散会让一个局部缺口先发生，再按空间距离逐步传递到周围；空间距离决定大致的失稳前沿，每个字符再叠加一个加性的局部释放抖动，所以相邻字符不会被锁成三字一组或规律横排，同时缺口仍然读作“一个洞在长大”而不是整张卡片一起溶解。缺口前沿的半径由角向噪声调制，因此洞口是不规则的瓣状轮廓而不是规整椭圆。选择“同列坍方（整列缺口）”时，会优先锁定代码卡片中部连续的几列，列内字符保持完整缺口和列级物理，每一列按中心到外围的连续时序单独打开。默认坍塌传播时长约 3.4 秒。只有掉落到花丛高度后才开始淡出并生成蝴蝶。

### 字符坠落的物理

字符不是“按帧位移的贴纸”，而是一块块受空气作用的薄片。物理使用真实单位（px、秒、px/s²），以固定 180Hz 子步积分，因此在 60Hz 和 144Hz 显示器上表现完全一致（实测 4 秒后位置漂移为 0.000px）；蝴蝶和花朵是运动学对象，以固定 60Hz 子步更新。

每个字符的迎风分量和掠风分量分别对应压差阻力与摩擦阻力，两者相差约 16 倍，形成各向异性阻力；力矩取两者的乘积项，于是字符会自发出现“兜风—减速—打滑—翻转”的往复，也就是真实纸片飘落的姿态。空气本身是一个由标量势解析求导得到的无散度涡旋场，气动力作用在相对风速上，所以相邻字符是被同一个涡旋卷着走的，会成团旋绕而不是各抖各的。字符的质量和迎风面积由字形实际墨迹量测得，`.` 和 `i` 明显比 `W` 和 `@` 飘得慢。

渲染上还有三项超出参考视频的处理：字符有一个离面倾角，会真的压扁并翻到背面（纯平面自转在数学上做不到这件事，但前缩设有易读性下限，否则字符在最常见的迎风姿态下会压成一条看不见的线）；字符分布在不同景深层，近的更大、扫过更快，远的更小更淡；快速翻滚时沿速度反方向拖出残影，且残影会同步回卷姿态，使模糊跟随翻滚而不只是平移。

坍塌位移严格单向：允许兜风一拍内的受限瞬时上冲（这是翻滚成立的前提），但字符永远不会升回它脱落的高度，画面上读不到回弹或向中心回聚。控制台把这些拆成“文字坍塌”“坠落物理”“字符渲染”三组参数，收尾速度、翻滚强度、涡旋强度与尺度、质量差异、伪 3D 翻滚、景深和运动模糊都可以实时调节。纸张纹理缓存和气流场网格预计算用于降低每帧开销；默认 160 个字符，数量范围限定为 100–220。控制台中的扇翅频率可以实时调节，默认频率已调低以保持更轻的线稿节奏。

花园生长时间轴为 8 秒，8 秒之后花朵保持完成状态，蝴蝶运动不停止。控制台放大为更易操作的实验面板，并将参数分为“文字坍塌”“蝴蝶飞行”和“指针扰动”三组。蝴蝶使用生态访花状态机：首次抵达出生时分配的花朵并触发生长，之后在接近、闭合环绕、花心悬停和邻花转访之间循环；邻花选择同时考虑距离和拥挤度，局部分离力避免蝴蝶叠成一团。围绕半径、环绕高度、轨道速度、轨道倾角、轨道呼吸、轨道漂移、花朵吸引、驻花时长、群体避让、飞行速度、大小和扇翅频率都可以独立调节。新参数会实时作用于已有蝴蝶，完成态也不需要重播。点击“恢复默认”只恢复参数，不会强制重播当前实验。每次重播使用同一个随机种子，所以调整参数时可以稳定比较差异。

指针移入 Canvas 后会触发局部互动。花朵保留可调的低频自然风动，指针会让整株花朵产生连续的左右姿态变化：根部固定不动，枝条控制点和花头终点沿同一条曲线移动，花朵主体始终连接在枝条末端，叶片也沿实际枝条曲线取点；不会再把偏移只加到花头造成“尸首分离”。蝴蝶在指针影响半径内受到二维排斥，逃离期间暂停访花计时，指针离开后先回到当前目标花朵，再继续生态循环。指针互动支持鼠标、触控笔和触摸输入，开关、花朵影响半径、扰动幅度、响应与回归速度、指针衰减、蝴蝶排斥半径、排斥强度和回归速度都可以在面板中实时调节。指针状态直接进入 Canvas 引擎，不触发 React 高频重渲染，也不减少字符、蝴蝶和有效花朵对象。花园中的每条可见花枝都由对应的花朵对象绘制，避免额外孤立根。
