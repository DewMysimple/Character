# 2026-08-31｜整株花朵指针联动修复

- 时间：2026-08-31（北京时间）
- 类型：`bug`
- 状态：`完成`
- 目标：修复指针扰动时花头与枝干分离的问题，让花朵主体带动枝干左右移动，同时保持根部固定。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- 指针偏移不再只叠加在花头主体，而是参与整株花朵的连续姿态计算。
- 根部坐标保持固定；枝条控制点和花头终点共同横移，花头绘制在枝条终点，叶片沿实际枝条曲线取点。
- 花朵和蝴蝶继续使用同一个动态花头坐标，指针响应不改变蝴蝶绑定关系，也不重播时间轴。

## 文件变更

- `src/engine/scene.ts`：新增二次曲线取点和统一花朵姿态计算；绘制、蝴蝶目标和指针距离检测复用同一坐标模型。
- `README.md` 与 `wiki_memory/`：记录根部固定、枝条连续跟随花头和禁止只偏移花头的约束。

## 测试与验证

- `npm run build`：通过，TypeScript 和 Vite 生产构建成功。
- `git diff --check`：通过，只有 Windows 换行格式提示。
- 静态检查确认指针偏移不再存在独立的花头绘制路径，花头和枝条终点均来自 `getFlowerPose`。
- 产物检查保持不包含 `node_modules`、`dist`、原始 MP4 或分析帧。

## 结果与下一步

- 结果：指针交互时根部不动，枝干连续弯曲并带动花头和叶片，消除“尸首分离”。
- 远程同步：本次代码和记忆更新提交后推送至 `origin/main`。
- 下一步：如需继续校准，重点观察大幅度指针偏移时枝条弯曲幅度与花头轨道的视觉连接。
