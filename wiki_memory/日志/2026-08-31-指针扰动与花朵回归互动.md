# 2026-08-31｜指针扰动与花朵回归互动

- 时间：2026-08-31（北京时间）
- 类型：`feature`
- 状态：`完成`
- 目标：让指针直接扰动 Canvas 中的花朵和蝴蝶，并保持蝴蝶在指针离开后回到各自花朵。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- Pointer Events 在 `AnimationCanvas` 内转换到 720×960 设计坐标，通过 `SceneEngine.setPointer` 传递，不经过 React 高频 state。
- 花朵新增固定相位的自然风动，并以花头距离计算局部左右涟漪；指针离开后用回归速度平滑恢复，不产生突兀跳变。
- 蝴蝶新增指针排斥半径、排斥强度和回归速度；排斥力有衰减和安全边界，离开影响范围后继续围绕原花朵轨道飞行。
- 参数面板新增指针互动开关和 9 个指针、花朵、蝴蝶参数，恢复默认只恢复参数，不重播当前时间轴。

## 文件变更

- `src/engine/types.ts`：增加 `ScenePointer`、花朵动态字段和指针互动配置及默认值。
- `src/engine/scene.ts`：增加花朵自然风动、局部指针偏移、蝴蝶排斥、安全边界和轨道回归。
- `src/components/AnimationCanvas.tsx`：监听 Pointer Events 并转换设计坐标，卸载时清理监听。
- `src/components/ControlPanel.tsx` 与 `src/styles.css`：增加指针扰动分组、开关和独立滑块。
- `README.md` 与 `wiki_memory/`：同步指针互动行为、参数语义、架构决策和任务日志。
