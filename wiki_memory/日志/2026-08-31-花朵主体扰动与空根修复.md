# 2026-08-31｜花朵主体扰动与空根修复

- 时间：2026-08-31（北京时间）
- 类型：`fix`
- 状态：`完成`
- 目标：让指针只扰动花朵主体，并修复完成画面中存在没有花朵的孤立根。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- `SceneEngine` 将自然风动拆为枝条 sway 和花头主体 offset。`pointerOffset` 只进入花瓣和花头位置，枝条曲线与叶片不再跟随指针偏移。
- 蝴蝶轨道中心继续读取当前花头位置，所以花头受到指针扰动时，绑定蝴蝶保持同一花朵归属。
- 移除独立 `StemSeed` 的构建和绘制。所有可见花枝统一由 `Flower` 绘制，避免静态额外根在完成态没有对应花朵。

## 文件变更

- `src/engine/scene.ts`：拆分花朵自然风动、枝条 sway 和花头主体位置；移除独立根集合及绘制路径。
- `src/engine/types.ts`：移除不再使用的 `StemSeed` 类型。
- `README.md` 与 `wiki_memory/`：记录主体扰动边界和空根修复约束。

## 测试与验证

- `npm run build`：通过，TypeScript 和 Vite 生产构建成功。
- `git diff --check`：通过。
- 静态检查确认 `drawStem`、`buildStems`、`this.stems` 和 `StemSeed` 不再被场景使用。
- 产物仍未包含 `node_modules`、`dist`、原始 MP4 或分析帧。

## 结果与下一步

- 结果：指针不会再拖动整根花枝，完成态不再生成额外的无花空根；自然风动、蝴蝶轨道和有效花朵数量保持现有逻辑。
- 远程同步：本次代码和记忆更新提交后推送至 `origin/main`。
- 下一步：如需继续校准，重点观察主体偏移幅度与花头和蝴蝶轨道的视觉连接。
