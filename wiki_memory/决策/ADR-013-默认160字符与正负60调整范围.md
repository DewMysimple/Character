# ADR-013｜默认 160 字符与正负 60 调整范围

## 状态

`active`

本决策只取代 ADR-005 的默认字符数量与滑块范围条款，以及 ADR-012 的「维持 420 字符」条款；局部传播、薄片气动、Canvas2D 和性能策略继续有效。

## 背景

用户明确要求将默认字符数量设为 160，并把可调阈值限制在默认值上下各 60。参考帧中的可见散落字符约为 100 至 150 个，较低默认密度也更接近目标画面，同时保留足够的调节空间。

## 决策

- `PARTICLE_COUNT_DEFAULT` 固定为 160。
- `PARTICLE_COUNT_MIN` 与 `PARTICLE_COUNT_MAX` 由默认值减、加 60 推导，当前范围为 100 至 220。
- 控制面板步长保持 10；默认值与边界集中定义在 `src/engine/types.ts`，面板直接引用，避免数值漂移。
- 调整字符数量仍触发场景重建与确定性 seek；不改变坍塌模式、字符物理、蝴蝶与花朵关系。

## 影响

- 默认画面中的字符云更克制，蝴蝶总量随默认字符数量降为 160。
- 100 至 220 的边界允许在稀疏与较密之间校准，但不再开放旧的 120 至 480 大跨度。
- 8 秒花园、整列缺口、相邻字符去批次化和固定步长物理必须在新默认值下重新验证。

## 验证方式

运行 `npm run build`；运行 `harness.html?check=1`，确认 8 秒花园仍全部开放、默认蝴蝶为 160、整列缺口与每行实际选中字符的相邻去批次化检查通过，并确认 100、160、220 三个数量档均生成同数量蝴蝶且 36 朵花全部开放；检查控制台字符数量滑块的最小值、默认值、最大值分别为 100、160、220。
