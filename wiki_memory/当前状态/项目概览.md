# 项目概览

## 项目名称

Character 字符物理实验。

## 项目目标

用一个无需外部素材的 Canvas 实验复刻参考视频开场的视觉逻辑：代码字符从卡片原始位置缺失并掉落，交叉淡化为蝴蝶，再触发下方花朵生长。

## 当前阶段

首个可运行版本已完成，已具备自动播放、重播、时间轴、响应式控制台和可实时调节的物理参数。默认使用 420 个字符填满代码行，从卡片中间一小处开始局部坍塌，再按空间距离逐步影响周围；默认传播时长约 3.2 秒，每个字符拥有独立的释放微偏移、初始速度和扰动相位，避免几个字符同步成为僵硬单元；进入花丛高度才替换为蝴蝶。控制台可切换四种文字变化形式并放慢坍塌或变形时长；其中“同列坍方（整列缺口）”会让中心连续几列先形成贯穿代码行的缺口，再按整列分组向外泄露，列内字符共享释放时刻和单向下落。蝴蝶只围绕各自绑定的花朵飞行，花园在 8 秒完成，花园完成后蝴蝶仍持续飞行。参数面板已放大并分为文字坍塌、蝴蝶飞行和指针扰动三组，围绕半径、环绕高度、轨道速度、轨道倾角、轨道呼吸、轨道漂移、花朵跟随、飞行速度、大小、扇翅频率以及花朵和蝴蝶的指针互动参数均可独立调节；恢复默认会恢复所有参数但不强制重播。指针移入 Canvas 后，花朵以根部固定的连续枝条姿态带动花头和叶片左右变化，蝴蝶会远离指针并在离开影响范围后回到自己的花朵轨道；可见花枝全部由对应花朵绘制，不再生成孤立空根。

## 主要用户或使用者

用于展示数字艺术和创意编程效果的个人实验项目。

## 核心目录

| 路径 | 用途 |
| --- | --- |
| `src/App.tsx` | React 页面与控制状态 |
| `src/components/` | Canvas 容器和悬浮控制台 |
| `src/engine/` | 场景类型、固定随机种子、粒子物理和绘制 |
| `src/styles.css` | 纸张主题、响应式布局和控件样式 |
| `wiki_memory/` | Agent 工程记忆 |
| `_analysis_frames/` | 本地视频分析帧，不进入 Git |

## 重要入口

- `npm run dev`：本地开发服务器。
- `npm run build`：TypeScript 检查和 Vite 生产构建。
- `src/main.tsx`：前端启动入口。
