# ADR-008｜指针扰动与花朵回归互动

## 状态

`active`

## 背景

用户希望在已有花朵自然风动和蝴蝶花朵轨道的基础上加入指针互动：指针附近的花朵产生左右扰动，蝴蝶受到指针排斥，并在指针不再影响后回到原来的花朵。

## 决策

- 使用原生 Pointer Events，只在 Canvas 上监听 `pointerenter`、`pointermove`、`pointerleave` 和 `pointercancel`，将坐标转换到固定 720×960 设计坐标后直接交给 `SceneEngine`。
- 花朵采用以花头为中心的局部距离衰减，生成横向动态偏移；自然风动使用固定随机相位，指针离开后使用无跳变的回归插值恢复。
- 花朵使用根部固定的连续二次曲线姿态：指针偏移同时作用于枝条控制点和花头终点，花朵主体绘制在枝条末端，叶片沿同一条枝条曲线布置，确保整株移动时不发生断裂。花枝由 `Flower` 自身绘制，不再额外叠加无花的独立根集合。
- 蝴蝶采用二维远离力，按排斥半径和衰减计算并限制安全边界；逃离时暂停生态状态计时，指针离开影响范围后切回 `approach`，先返回当前目标花朵再继续访花，不切换目标、不重播。
- 将指针开关、自然风动、花朵影响半径、扰动幅度、响应与回归速度、衰减、蝴蝶排斥半径、排斥强度和回归速度作为独立 `PhysicsConfig` 参数，通过现有 ref 数据流实时生效。
- 指针扰动属于持续运动层；即使场景时间已经停在 8 秒，只要播放状态仍开启，`stepAgents` 仍必须使用实际固定子步增量更新花朵和蝴蝶。

## 理由

Canvas 直接接收指针能避免连续坐标触发 React 高频渲染。花朵的局部横向偏移能保留纸张线稿的克制感；蝴蝶使用持续排斥和轨道回归，可以同时提供互动反馈和稳定的花朵归属。

## 影响

- 正面影响：鼠标、触控笔和触摸都能直接扰动画面，完成态仍可探索，蝴蝶不会永久脱离花朵。
- 代价或风险：新增参数会进一步增加移动端面板高度，需要保留滚动；指针力必须限制在安全边界内，避免遮挡构图或破坏花朵触发。

## 验证方式

检查 375px、768px、1440px 视口和 Canvas Pointer Events；完成态移动指针确认附近花朵左右变化、蝴蝶远离指针，移开后回到花朵轨道；关闭互动和恢复默认确认不重播、不重建粒子；运行 `npm run build`、`git diff --check`、记忆 lint 和产物检查。
