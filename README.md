# 字符物理实验

这是一个 React + Vite + TypeScript 的 Canvas 数字艺术实验，用程序化线稿复刻参考视频的视觉逻辑：

代码卡片默认使用 420 个可变字符填满各行。文字从卡片中间的一小处开始缺失和下沉，再按距离逐步影响周围，像建筑局部坍方向外扩散一样经历一段可观察的实时物理过程；当字符进入花丛高度后，才经过艺术指导式的状态替换成为蝴蝶。蝴蝶飞向对应花朵并持续盘旋，花园在 8 秒内完成生长。

## 启动

在 Windows PowerShell 中执行：

```powershell
cd "C:\Users\Administrator\Desktop\Character"
npm install
npm run dev
```

然后打开 Vite 输出的本地地址，默认是 `http://localhost:5173`。

## 结构

- `src/engine/types.ts`：粒子、蝴蝶、花朵和控制参数类型。
- `src/engine/scene.ts`：固定随机种子的场景引擎、物理更新和 Canvas 绘制。
- `src/components/AnimationCanvas.tsx`：高 DPI Canvas、ResizeObserver 和 requestAnimationFrame 生命周期。
- `src/components/ControlPanel.tsx`：播放、时间轴、坍塌形式和物理参数控制。
- `src/App.tsx`：React 状态与动画引擎之间的控制层。

## 设计说明

这个工程不使用原始视频作为背景，也不依赖原作者源码。字符、蝴蝶和花朵是三个独立对象，转换通过状态机和透明度交叉淡化完成。控制台的“文字变化形式”提供“局部扩散”“同列坍方”“中心聚拢”“波纹塌落”四种路径，默认局部扩散会让一个局部缺口先发生，再按空间距离逐步传递到周围；字符一旦被波及就从自己的原始列立即受重力下坠，不追踪中心目标，也没有中间汇聚阶段。坍塌时长和变形时长都可以放慢，以便观察字符从原位脱落、受力、旋转和下坠的连续过程。下落阶段垂直速度保持单向，不会出现减速上浮或回弹。只有掉落到花丛高度后才开始淡出并生成蝴蝶。重力、风力、中心吸引、阻尼、旋转和扰动负责提供物理感，花朵的茎、叶片和花瓣则按事件逐步生长。纸张纹理缓存、粒子扰动预计算和单向位置更新用于降低每帧开销，不减少字符或动态数量。控制台中的扇翅频率可以实时调节，默认频率已调低以保持更轻的线稿节奏。

花园生长时间轴为 8 秒，8 秒之后花朵保持完成状态，蝴蝶运动不停止。每次重播使用同一个随机种子，所以调整参数时可以稳定比较差异。
