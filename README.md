# 字符物理实验

这是一个 React + Vite + TypeScript 的 Canvas 数字艺术实验，用程序化线稿复刻参考视频的视觉逻辑：

代码卡片默认使用 420 个可变字符填满各行。文字从卡片中间的一小处开始缺失和下沉，再按距离逐步影响周围，像建筑局部坍方向外扩散一样经历一段约 3.2 秒的可观察实时物理过程。局部扩散模式下以空间传播为骨架，但每个字符还拥有独立的释放排序扰动、初始横向速度、下落速度和旋转相位，不会以几个字符为一个僵硬的坍塌单元；同列坍方模式则保留整列缺口的结构化释放。当字符进入花丛高度后，才经过艺术指导式的状态替换成为蝴蝶。蝴蝶会分散到花丛上方的飞行层持续盘旋，花园在 8 秒内完成生长。

## 启动

在 Windows PowerShell 中执行：

```powershell
cd "C:\Users\Administrator\Desktop\Character"
npm install
npm run dev
```

然后打开 Vite 输出的本地地址，默认是 `http://localhost:5173`。

## 结构

- `src/engine/types.ts`：粒子、蝴蝶、花朵和控制参数类型。
- `src/engine/scene.ts`：固定随机种子的场景引擎、物理更新和 Canvas 绘制。
- `src/components/AnimationCanvas.tsx`：高 DPI Canvas、ResizeObserver 和 requestAnimationFrame 生命周期。
- `src/components/ControlPanel.tsx`：播放、时间轴、分组参数、蝴蝶轨道实验台、指针扰动实验台和恢复默认控制。
- `src/App.tsx`：React 状态与动画引擎之间的控制层。

## 设计说明

这个工程不使用原始视频作为背景，也不依赖原作者源码。字符、蝴蝶和花朵是三个独立对象，转换通过状态机和透明度交叉淡化完成。控制台的“文字变化形式”提供“局部扩散”“同列坍方”“中心聚拢”“波纹塌落”四种路径，默认局部扩散会让一个局部缺口先发生，再按空间距离逐步传递到周围；空间距离只负责决定大致的失稳前沿，每个字符再混入独立的确定性释放排序扰动，所以相邻字符不会被锁成三字一组或规律横排。字符一旦被波及就从自己的原始列立即受重力单向下坠，不追踪中心目标，也没有中间汇聚阶段。选择“同列坍方（整列缺口）”时，会优先锁定代码卡片中部连续的几列，整列字符在同一释放波中下落，再以整列为单位向外泄露，避免变成零散字母。坍塌时长和变形时长都可以放慢，以便观察字符从原位脱落、受力、旋转和下坠的连续过程；默认坍塌传播时长已延长到约 3.2 秒。下落阶段垂直速度保持单向，不会出现减速上浮或回弹。只有掉落到花丛高度后才开始淡出并生成蝴蝶。重力、风力、中心吸引、阻尼、旋转和扰动负责提供物理感，长帧会被拆成更小的积分步，花朵的茎、叶片和花瓣则按事件逐步生长。纸张纹理缓存、粒子扰动预计算和单向位置更新用于降低每帧开销，不减少字符或动态数量。控制台中的扇翅频率可以实时调节，默认频率已调低以保持更轻的线稿节奏。

花园生长时间轴为 8 秒，8 秒之后花朵保持完成状态，蝴蝶运动不停止。控制台放大为更易操作的实验面板，并将参数分为“文字坍塌”“蝴蝶飞行”和“指针扰动”三组。蝴蝶只使用围绕各自花朵飞行的模式；围绕半径、环绕高度、轨道速度、轨道倾角、轨道呼吸、轨道漂移、花朵跟随、飞行速度、大小和扇翅频率都可以独立调节。新参数会实时作用于已有蝴蝶，完成态也不需要重播。点击“恢复默认”只恢复参数，不会强制重播当前实验。每次重播使用同一个随机种子，所以调整参数时可以稳定比较差异。

指针移入 Canvas 后会触发局部互动。花朵保留可调的低频自然风动，指针会让整株花朵产生连续的左右姿态变化：根部固定不动，枝条控制点和花头终点沿同一条曲线移动，花朵主体始终连接在枝条末端，叶片也沿实际枝条曲线取点；不会再把偏移只加到花头造成“尸首分离”。蝴蝶在指针影响半径内受到二维排斥，指针离开后按回归速度回到各自花朵轨道。指针互动支持鼠标、触控笔和触摸输入，开关、花朵影响半径、扰动幅度、响应与回归速度、指针衰减、蝴蝶排斥半径、排斥强度和回归速度都可以在面板中实时调节。指针状态直接进入 Canvas 引擎，不触发 React 高频重渲染，也不减少字符、蝴蝶和有效花朵对象。花园中的每条可见花枝都由对应的花朵对象绘制，避免额外孤立根。
