# 2026-09-01｜恢复完成态持续飞行与指针扰动

- 时间：2026-09-01（北京时间）
- 类型：`bug`
- 状态：`完成`
- 目标：恢复 8 秒花园完成后的蝴蝶花朵轨道、花朵自然风动和指针扰动。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 根因与修复

- 气动物理改为固定步长后，`advance()` 仍通过 `time - startTime` 计算代理更新量；`time` 在 8 秒被封顶，因此后续 `stepAgents` 收到的增量恒为零。
- 改为累计本帧实际执行的 `PHYSICS_DT` 得到 `motionDelta`。叙事时间仍停在 `8.00s`，但 `motionTime`、蝴蝶轨道、花朵风动和指针响应继续推进。
- 为校准工装增加只读蝴蝶状态，并新增“8 秒后持续运动”回归项，同时检查蝴蝶位移和花朵指针偏移。

## 文件变更

- `src/engine/scene.ts`：分离封顶场景时间与持续代理增量，增加工装用 `debugButterflies()`。
- `src/harness.ts`：新增第十项完成态持续飞行与指针扰动检查。
- `README.md`：更新工装检查数量和覆盖范围。
- `wiki_memory/`：同步当前状态、模块知识和 ADR 实现约束。

## 测试与验证

- `npm run build`：通过，TypeScript 与 Vite 生产构建成功。
- `harness.html?check=1`：十项全部通过；完成态 1 秒内蝴蝶轨道最大位移 `293.66px`，花朵指针摆动 `13.55px`，蝴蝶相对无指针对照偏转 `9.41px`，时间轴保持 `8.00s`。
- 浏览器完成态慢速检查：在 `8.00 / 8.00s`、160 只蝴蝶和 36 朵花的状态下，以控制台最低 `0.25x` 速度移动指针并比较前后 Canvas，画面持续变化且轨道、花朵连接关系正常。
- 产物与 Git 检查：提交前确认 `node_modules`、`dist`、原始 MP4 和分析帧均未加入版本库。

## 结果与下一步

- 结果：自动播放越过 8 秒后，蝴蝶继续围绕各自花朵飞行；指针靠近时花朵和蝴蝶继续响应，离开后回归原轨道。
- 下一步：如继续校准，只需调整已有环绕与指针参数，不应再次耦合 `stepAgents` 与封顶场景时间。
