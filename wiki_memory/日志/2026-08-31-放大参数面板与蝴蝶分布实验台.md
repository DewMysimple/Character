# 2026-08-31｜放大参数面板与蝴蝶分布实验台

- 时间：2026-08-31（北京时间）
- 类型：`feature`
- 状态：`完成`
- 目标：放大参数面板，按文字坍塌和蝴蝶飞行分组，并增加蝴蝶分布与飞行个性化调节。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- 默认分布仍为花丛上方均匀分散，新增左右两翼、中心扩散和全场宽幅漂游模式。
- 将原有单一 `butterflySpread` 拆为横向分布、纵向高度、漫游幅度、聚集度、飞行速度和大小；扇翅频率继续保留。
- 目标点每帧从固定随机种子和当前配置计算，完成态调参直接影响已有蝴蝶，不重播、不累积粒子。
- 控制台桌面宽度调整到约 `460px`，移动端使用更高的可滚动底部面板。

## 文件变更

- `src/engine/types.ts`：增加 `ButterflyDistribution` 和蝴蝶飞行配置字段，更新默认值。
- `src/engine/scene.ts`：增加四种确定性分布目标、实时飞行参数和动态蝴蝶大小。
- `src/components/ControlPanel.tsx`：重组参数分区，增加分布模式和六个个性化滑块。
- `src/styles.css`：放大面板、提高控件触达面积并增加移动端单列滚动布局。
- `README.md` 与 `wiki_memory/`：记录新参数语义和架构决策。

- `npm run build`：通过，TypeScript 和 Vite 生产构建成功。
- 浏览器三视口验证：`1440x900` 面板宽 `460px`，`768x1024` 面板宽 `460px`，`375x812` 面板宽 `347px`；参数区可滚动，三个视口均无横向溢出。
