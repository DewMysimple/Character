# 字符数量默认 160 与范围收窄

## 用户要求

将默认字符数量改为 160，并将调整阈值限制为默认值上下各 60。

## 实现

- `src/engine/types.ts` 集中定义默认值 160、最小值 100 和最大值 220，`DEFAULT_PHYSICS.particleCount` 引用默认常量。
- `src/components/ControlPanel.tsx` 的字符数量滑块直接引用最小/最大常量，步长保持 10。
- `src/harness.ts` 的去批次化检查改为比较每一行实际选中的相邻字符，避免低字符数量没有连续原始列时出现 `0/0` 空通过；新增字符数量上下界检查，覆盖 100、160、220 三档的蝴蝶数量和 8 秒花园完成状态。
- 更新 README、当前状态、模块知识和决策记录；新增 ADR-013，明确取代旧的 420 默认值与 120 至 480 范围条款。

## 验证

- `npm run build` 通过，Vite 转换 35 个模块，生产脚本约 230.20 kB。
- `harness.html?check=1` 九项全部通过：位移单向、60Hz/144Hz 一致、seek 与播放一致、复播确定性、8 秒花园、整列缺口、实际选中字符去批次化、单帧成本和字符数量上下界。
- 默认配置在 8 秒时生成 160 只蝴蝶并开放 36/36 朵花；100、160、220 三档分别生成同数量蝴蝶，三档均开放 36/36 朵花。
- 去批次化检查覆盖 148 对每行实际选中的相邻字符，其中 6 对释放时差小于 8ms；不再出现 `0/0` 空通过。
- 默认 160 字符的确定性校准帧覆盖 1.4、2.0、2.6、3.2、4.0、5.0 秒，中心缺口和下落字云连续，5 秒花丛触发正常。
- 控制台渲染结果确认字符数量输入为 `min=100`、`value=160`、`max=220`、`step=10`。
- `git diff --check` 通过；`git status` 与版本库文件检查确认未纳入 `dist`、`node_modules`、MP4 或 `_analysis_frames`。
