# 字符物理场景

## 一句话结论

`SceneEngine` 在固定的 720×960 逻辑画布中以半隐式 Euler 更新字符和蝴蝶，再把结果绘制成纸张色的竖屏构图。

## 适用范围

适用于前 8 秒的自动播放、暂停、重播、时间轴跳转和物理参数调节，以及 8 秒后的蝴蝶持续飞行，不负责编辑器输入或真实字体点云变形。

## 详细内容

- 默认 420 个字符从代码卡片各行取样，从卡片中部的一小处开始缺失，按空间距离逐步传播到周围；字符一旦释放就从原始列立即受重力下坠，不追踪坍塌中心、不减速汇聚，也不允许垂直回浮，再叠加风力、阻尼、旋转和扰动形成下落字符流。`column-collapse`、`center-collapse` 与 `wave-collapse` 只改变释放传播顺序。
- 字符只有在达到 650 至 776 的花丛高度并完成最小下落时间后才进入变形窗口；字符降低透明度，蝴蝶根据对应出生点提高透明度，在花丛上方的分散飞行层持续盘旋，并保留对应花朵的触发关系。
- 蝴蝶的 `flightPhase` 负责轨道相位，`wingPhase` 负责扇翅；`PhysicsConfig.wingBeatFrequency` 以 Hz 控制扇翅频率。当前只保留围绕花朵飞行，每只蝴蝶的 `flowerX`、`flowerY` 是固定轨道中心，`butterflyOrbitRadius`、`butterflyOrbitHeight`、`butterflyOrbitSpeed`、`butterflyOrbitTilt`、`butterflyOrbitWobble`、`butterflyOrbitDrift` 和 `butterflyFlowerAttraction` 分别控制水平半径、垂直半径、角速度、椭圆倾角、周期呼吸、低频漂移和花头跟随。目标点每帧由花头中心和当前轨道参数计算，使已有蝴蝶在完成态也能平滑响应，不重建粒子。
- `ScenePointer` 由 `AnimationCanvas` 从 Pointer Events 坐标转换而来，通过 `SceneEngine.setPointer` 直接进入引擎。花朵用 `windPhase`、`pointerOffset` 和 `flowerWindStrength` 生成自然风动与局部横向涟漪；蝴蝶在 `butterflyPointerRadius` 内按 `pointerFalloff` 受到 `butterflyPointerRepulsion` 的远离力，指针离开后由 `butterflyPointerReturn` 回到动态花头轨道。所有响应都在 Canvas 循环内完成，不触发 React 每帧重渲染。
- 蝴蝶达到花朵触发区域后，花茎、叶片、花瓣按进度依次绘制。
- 花园进度在 8 秒时完成，`motionTime` 继续增长，因此花朵完成不会停止蝴蝶运动。
- 花朵颜色、字符颜色和布局都来自固定随机种子，便于复播比较。
- `AnimationCanvas.tsx` 负责 ResizeObserver、高 DPI 尺寸和动画循环清理；React 只接收低频快照。

## 常见问题或陷阱

- 不要在 Canvas 的每一帧直接写 React state，否则会造成不必要的树重渲染。
- 修改粒子数量后要重新初始化场景，不能把旧粒子数组继续累加。
- 坍塌时长和变形时长影响蝴蝶出生时机和花朵触发密度，调参后需要重新检查 1.4 至 6.5 秒区间；高字符数量下要同时观察 Canvas 帧率和文字行的覆盖密度。8 秒完成态仍要检查蝴蝶是否持续更新，以及范围、风力、中心吸引和扇翅频率是否无需重播即可响应。纸张背景纹理与粒子扰动已分别缓存和预计算，避免把性能优化转化为减少动态对象。
- 指针事件只在 Canvas 上监听并在卸载时移除；面板覆盖区域不应继续传递场景指针。指针关闭或离开后，花朵使用回归速度回到自然风动，蝴蝶使用回归转向回到各自花朵，不要通过重播或重建粒子实现恢复。
