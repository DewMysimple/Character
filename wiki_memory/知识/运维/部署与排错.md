# 部署与排错

## 一句话结论

本项目是静态 Vite 前端，重点运维检查是依赖、构建、端口、响应式布局和远程 Git 状态。

## 适用范围

适用于本地开发预览和提交前检查。

## 详细内容

- 页面开发：`npm run dev`，默认 `http://localhost:5173`。
- 构建检查：`npm run build`，确认 `dist/` 生成且不含 MP4。
- 远程检查：`git remote -v`、`git log --oneline -5`、`git status --short --branch`。
- 视觉检查：桌面和移动宽度下确认 Canvas 保持 3:4，控制台不遮挡主体。

## 常见问题或陷阱

- 端口被占用时，使用 Vite 实际输出地址，不要假设一定是 5173。
- `npm install` 后应保留 `package-lock.json`，确保依赖可复现。
- GitHub 推送需要远程仓库写权限和有效凭据。
