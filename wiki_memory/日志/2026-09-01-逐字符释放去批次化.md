# 逐字符释放去批次化

## 目标

修复用户观察到的“很明显的一批一批、三俩成行”的僵硬坍塌感，使默认局部扩散模式更接近参考视频中每个字符独立失稳、独立掉落的物理表现。

## 根因

此前释放时刻主要由字符到坍塌中心的规则距离决定。代码字符天然排列在规则的行列网格中，等距字符因此会在近似相同的时间层被激活；即便各粒子已经有随机旋转和微小速度，画面仍会被读成成行或小批次同步坍落。

## 实现

- 在 `src/engine/scene.ts` 增加独立释放排序函数。
- 默认局部模式以空间距离保留中心缺口向外传播的骨架，再叠加每字符固定种子的独立噪声排序，字符不再共享等距释放时间。
- 非整列模式保留同样的个体释放原则；`column-collapse` 继续保持完整列组共享释放时刻，因为该模式的语义就是整列缺口。
- 将非整列模式激活时的独立横向初速从 `0.12` 提高到 `0.28` 的随机范围，增强每个字符自己的侧向轨迹差异。
- 删除局部模式额外的释放抖动尾窗，让阶段边界与实际释放窗口一致。

## 验证

- `npm run build` 通过。
- `git diff --check` 通过。
- 使用固定种子计算默认 420 个字符的释放序列，确认释放排序不再只由网格等距关系决定。
- 未减少字符、蝴蝶或花朵数量，未修改整列缺口模式的整列语义。

## 结果

默认局部扩散模式现在是“空间传播 + 每字独立排序 + 每字独立侧向物理”，相邻字符不会再固定成三字一组或规律横排；参考视频对照所需的中心缺口、持续传播和单向下落仍然保留。
