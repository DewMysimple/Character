# 2026-08-31｜局部坍塌传播与性能优化

- 时间：2026-08-31（北京时间）
- 类型：`feature`
- 状态：`完成`
- 目标：让坍塌从一个局部点开始逐步影响周围，消除回弹，并解决高字符量下的明显卡顿。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- 默认变化形式改为 `local-collapse`，由代码卡片中心附近的小范围缺口按空间距离向周围传播，不再让整张卡片同时坍塌。
- 坍塌阶段使用单向无过冲位置推进，下落阶段垂直速度限制为非负，避免字符回弹。
- 保留 `column-collapse`、`center-collapse` 和 `wave-collapse`，通过控制台“文字变化形式”切换。
- 默认字符数提高到 420，坍塌时长为 1.4 秒，变形时长为 1.05 秒，均可在面板调节。
- 缓存纸张背景纹理，预计算字符扰动相位，不通过减少字符或蝴蝶数量来换取性能。

## 文件变更

- `src/engine/types.ts`：新增局部坍塌模式、坍塌时长、字符预计算扰动字段，默认字符数提高到 420。
- `src/engine/scene.ts`：实现局部距离传播、无回弹位置推进、垂直单向下落、背景 Canvas 缓存和粒子扰动预计算。
- `src/components/ControlPanel.tsx`：新增文字变化形式选择、坍塌时长参数和 120 至 480 字符数量范围。
- `src/styles.css`：增加变化形式下拉控件样式。
- `README.md`：同步局部坍塌、无回弹与性能策略说明。
- `wiki_memory/`：新增 ADR-005，更新当前状态、模块知识、决策索引和本日志。
