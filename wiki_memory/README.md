## 维护方式

每次完成代码、配置或文档修改后，先验证项目，再同步一篇任务日志；若结论会影响未来工作，同时更新对应长期页面。随后创建 Git 提交并推送到 `origin`。

原始 MP4 和 `_analysis_frames/` 是本地参考资料，已被 Git 忽略，不应进入提交或构建产物。
