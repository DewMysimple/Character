# ADR-006｜完成态蝴蝶分散飞行与参数响应

## 状态

`superseded by ADR-007`

## 背景

花园在 8 秒完成后，蝴蝶仍应保持持续飞行，但原实现把目标点放在花朵低位，轨道半径也较小，导致蝴蝶视觉上集中在画面下方。部分参数只作用于字符阶段，完成态调节时反馈不明显；同时用户需要不重播实验就能恢复参数默认值。

## 决策

- 将蝴蝶目标点分布到花丛上方的 `322` 至 `682` 逻辑画布高度，并按固定随机种子分配横向目标，保留花朵触发坐标作为独立关系。
- 为每只蝴蝶叠加低频宽幅漫游和更大的局部轨道，`butterflySpread` 直接实时缩放这两层运动范围。
- `centerAttraction` 同时参与蝴蝶跟随目标点的转向强度，风力和 `wingBeatFrequency` 持续参与完成态更新；`motionTime` 在时间轴到 8 秒后继续增长。
- 参数面板增加“恢复默认”，只把 React 参数恢复为 `DEFAULT_PHYSICS`，不重置时间轴、不强制重播；受影响的 Canvas 参数通过 ref 同步到引擎。

## 理由

花丛上方的飞行层能保留花朵作为视觉锚点，同时给蝴蝶足够的垂直和横向呼吸空间。将花朵触发坐标与飞行目标分离，可以避免为了触发花朵而把所有蝴蝶拉回低位。完成态继续更新和不重播恢复让控制台对观众仍然是可操作的实验工具。

## 影响

- 正面影响：蝴蝶不再全部堆积在下方，完成后调参可立即观察范围、风力、吸引力和扇翅变化。
- 代价或风险：飞行层与花朵头部不是完全重合，后续若调整花园构图，需要同时检查目标分布、触发距离和 8 秒完成时间。

## 验证方式

检查 8 秒完成态显示 420 只蝴蝶和 36 朵花，连续画布采样在时间间隔后发生变化；调节“蝴蝶范围”后保持 `8.00 / 8.00s` 且面板立即更新；点击“恢复默认”后范围回到 `1.00x`，不触发重播；检查 `npm run build`、`git diff --check` 和记忆 lint。

## 后续决策

参数模型中的单一 `butterflySpread` 已由 [[决策/ADR-007-蝴蝶分布实验台与大参数面板|ADR-007]] 拆分为分布模式、横向分布、纵向高度、漫游幅度、聚集度、飞行速度和大小；本页保留完成态持续飞行、花朵触发坐标独立和恢复默认不强制重播等历史结论。
