# 2026-08-31｜中心坍塌与花丛变形

- 时间：2026-08-31（北京时间）
- 类型：`feature`
- 状态：`完成`
- 目标：降低并开放蝴蝶扇翅频率，增强文字从中心坍塌到花丛下落的实时物理过程，并延迟到花丛高度才生成蝴蝶。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- 新增 `PhysicsConfig.wingBeatFrequency`，默认 2.8Hz，控制台以滑块实时调节。
- 字符按源位置到中心坍塌点的距离错峰释放，中部优先从代码卡片缺失。
- 释放后先进行中心弹簧聚拢，再进行增强重力下落；达到花丛高度且完成最小下落时间后才交叉淡化为蝴蝶。

## 文件变更

- `src/engine/types.ts`：新增扇翅频率、字符坍塌时机、花丛高度门槛和蝴蝶扇翅相位字段。
- `src/engine/scene.ts`：实现中心坍塌弹簧、向下加速度、下落距离门槛、独立扇翅相位和更强的花朵目标导航。
- `src/components/ControlPanel.tsx`：新增扇翅频率控制，并同步动效说明。
- `README.md`：记录中心坍塌、花丛高度变形和扇翅调节方式。
- `wiki_memory/`：新增 ADR-004、本次任务日志并更新当前状态、模块知识和决策索引。

## 测试与验证

- `npm run build`：通过。
- 浏览器阶段检查：约 1.8 秒可见中心聚拢字符，约 2.8 秒开始在花丛高度附近出现少量蝴蝶，约 3.3 秒字符仍在下落并持续生成蝴蝶，约 5.4 秒生成 17 朵花，约 7.9 秒生成 36 朵花。
- 视觉检查：移动端画面显示卡片中部优先缺字、字符向底部中心汇聚后形成下落流；字符在进入花丛高度后才交叉淡化为蝴蝶。

## 结果与下一步

- 结果：三项动效调整已完成，默认扇翅节奏已降低，参数面板可实时调整。
