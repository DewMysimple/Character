# 2026-08-31｜围绕花朵飞行模式

- 时间：2026-08-31（北京时间）
- 类型：`feature`
- 状态：`完成`
- 目标：在现有蝴蝶分布实验台中增加围绕各自花朵飞行的模式。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- 新增 `flower-orbit` 分布模式，使用每只蝴蝶绑定的 `flowerX`、`flowerY` 作为局部轨道中心。
- 花朵轨道使用独立的横向和纵向缩放，漫游幅度只增加低频漂移，避免把“围绕花朵”变成所有蝴蝶向同一位置聚集。
- 其他分布模式保持原行为；切换模式时只更新已有蝴蝶的目标和转向，不重建粒子、不重播，也不改变花朵触发坐标。
- 围绕花朵模式允许目标延伸到花头安全区域，保证较低花朵也能成为可见的飞行锚点。

## 文件变更

- `src/engine/types.ts`：为 `ButterflyDistribution` 增加 `flower-orbit`。
- `src/components/ControlPanel.tsx`：在蝴蝶分布下拉框增加“围绕花朵飞行”。
- `src/engine/scene.ts`：将花朵绑定坐标作为轨道中心，按横向分布和纵向高度缩放局部环绕范围，并保留实时漫游和飞行参数。
- `README.md` 与 `wiki_memory/`：记录第五种分布模式、参数语义和验证结论。

## 测试与验证

- `npm run build`：通过，TypeScript 和 Vite 生产构建成功。
- 浏览器完成态验证：下拉框包含 `canopy`、`sides`、`center`、`full-field`、`flower-orbit` 五个选项；切换到 `flower-orbit` 后时间保持 `8.00 / 8.00s`，数量保持字符 `0`、蝴蝶 `420`、花朵 `36`，画布采样发生变化。
- `git diff --check`：通过；未把 `node_modules`、`dist`、原始 MP4 或分析帧加入 Git。
