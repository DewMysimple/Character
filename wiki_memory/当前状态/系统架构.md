# 系统架构

## 架构概览

页面采用 React 控制壳加原生 Canvas 场景引擎。React 管理播放状态、参数和面板显示；Canvas 在单个动画循环中绘制代码卡片、文字粒子、蝴蝶线稿和花朵线稿。

## 模块关系

| 模块 | 职责 | 依赖 | 入口 |
| --- | --- | --- | --- |
| `App.tsx` | 保存控制参数，连接引擎快照和面板 | React、SceneEngine | `src/main.tsx` |
| `AnimationCanvas.tsx` | 创建高 DPI Canvas、ResizeObserver 和动画生命周期 | React、SceneEngine | `App.tsx` |
| `ControlPanel.tsx` | 播放、重播、时间轴、速度和物理参数 | React | `App.tsx` |
| `scene.ts` | 场景状态机、半隐式 Euler 更新和 Canvas 绘制 | Canvas API、类型定义 | `AnimationCanvas.tsx` |
| `types.ts` | Stage、PhysicsConfig、粒子和场景快照类型 | 无 | `scene.ts` |

## 数据流

用户操作先更新 React 参数。连续数值通过 ref 同步到 Canvas 引擎，避免每帧重新渲染 React 树。引擎根据时间和参数更新对象，并以低频快照更新面板上的阶段、进度和数量。

## 场景阶段

- `intro`：0.0 至 1.4 秒，显示代码卡片和植物轮廓。
- `falling`：1.4 至 2.8 秒，字符从卡片底部释放。
- `morphing`：2.5 至 3.8 秒，字符淡出、蝴蝶淡入。
- `bloom`：3.2 至 5.0 秒，蝴蝶扩散并触发花茎、叶片和花瓣生长。

## 运行与部署

开发环境使用 Vite，默认端口为 5173；若端口占用，Vite 会选择下一个可用端口。生产构建由 `tsc -b && vite build` 完成，产物位于 `dist/`，不包含参考视频。
