# 工程决策

- [[决策/ADR-001-Canvas与React控制壳|ADR-001：Canvas 与 React 控制壳]]：确定动画渲染和 UI 状态的边界。
- [[决策/ADR-002-状态替换与固定随机种子|ADR-002：状态替换与固定随机种子]]：确定字符到蝴蝶的稳定实现方式。
  - [[决策/ADR-003-8秒花园与持续飞行|ADR-003：8 秒花园与持续飞行]]：确定花园时间轴与无限蝴蝶运动的边界。
- [[决策/ADR-004-中心坍塌与花丛变形触发|ADR-004：中心坍塌与花丛变形触发]]：确定字符的中心坍塌物理和花丛高度变形门槛。
- [[决策/ADR-005-局部坍塌传播与性能缓存|ADR-005：局部坍塌传播与性能缓存]]：确定从单点向周围传播的无回弹坍塌和不减少动态对象的性能优化。
- [[决策/ADR-006-完成态蝴蝶分散飞行与参数响应|ADR-006：完成态蝴蝶分散飞行与参数响应]]：确定蝴蝶在花丛上方的分散飞行层、完成态持续更新和参数恢复默认行为。
- [[决策/ADR-007-蝴蝶分布实验台与大参数面板|ADR-007：蝴蝶分布实验台与大参数面板]]：确定分组面板、围绕花朵飞行模式和完成态实时调节字段。
- [[决策/ADR-008-指针扰动与花朵回归互动|ADR-008：指针扰动与花朵回归互动]]：确定 Canvas Pointer Events、花朵局部涟漪、蝴蝶排斥与花朵轨道回归。
- [[决策/ADR-009-同列坍方整列缺口传播|ADR-009：同列坍方整列缺口传播]]：确定同列模式以连续列为缺口单元，按整列分组向外泄露。（已被 ADR-011 取代）
- [[决策/ADR-010-参考视频校准与逐字符坍塌物理|ADR-010：参考视频校准与逐字符坍塌物理]]：确定默认局部模式的逐字符释放、延长传播窗口和源文字交接淡出。（垂直速度非负条款已被 ADR-012 取代）
- [[决策/ADR-011-同列坍方单列连续泄露|ADR-011：同列坍方单列连续泄露]]：确定整列仍为最小结构单位，但传播粒度收窄为单列连续泄露。
- [[决策/ADR-012-薄片气动翻滚与伪3D渲染|ADR-012：薄片气动翻滚与伪 3D 渲染]]：确定不引入外部物理库，字符改用固定 180Hz 的薄片气动模型与无散度涡旋场，单向性由速度改为位移，并加入伪 3D 翻面、景深与运动模糊。
- [[决策/ADR-013-默认160字符与正负60调整范围|ADR-013：默认 160 字符与正负 60 调整范围]]：将默认字符数量设为 160，并把控制台范围收窄为 100 至 220。
