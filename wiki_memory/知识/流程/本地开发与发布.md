# 本地开发与发布

## 一句话结论

依赖安装后用 Vite 开发服务器预览，每次修改完成都执行构建、提交并推送到 `origin/main`。

## 适用范围

适用于本仓库所有代码、配置和项目文档修改。

## 详细内容

- 开发：`cd "C:\Users\Administrator\Desktop\Character"`、`npm install`、`npm run dev`。
- 构建：`npm run build`。
- 预览：`npm run preview`。
- 修改交付：`git status`、`npm run build`、`git add .`、`git commit -m "feat: describe the change"`、`git push origin main`。

如端口 5173 被占用，以 Vite 输出的 Local 地址为准。推送凭据由本机 Git Credential Manager 或 SSH 配置提供，不在记忆文件中记录令牌。

## 常见问题或陷阱

- `node_modules/` 和 `dist/` 不应提交。
- 原始 MP4 体积过大，已由 `.gitignore` 排除；不要用 `git add -f` 强行加入。
- 如果远程已有提交，先获取并确认历史关系，再决定合并策略，不要无确认强制推送。
