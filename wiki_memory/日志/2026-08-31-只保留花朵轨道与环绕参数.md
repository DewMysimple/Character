# 2026-08-31｜只保留花朵轨道与环绕参数

- 时间：2026-08-31（北京时间）
- 类型：`feature`
- 状态：`完成`
- 目标：移除其他蝴蝶分布模式，只保留围绕花朵飞行，并把环绕行为拆成可实时调节的独立参数。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- `PhysicsConfig` 不再保留分布模式和泛化的横向、纵向、聚集参数，改用花朵轨道专用字段。
- 新增围绕半径、环绕高度、轨道速度、轨道倾角、轨道呼吸、轨道漂移和花朵跟随参数，继续保留飞行速度、大小和扇翅频率。
- 控制面板以固定状态展示“围绕花朵飞行”，不再提供其他分布模式的下拉选项。
- 每只蝴蝶继续以自己的 `flowerX`、`flowerY` 为中心，轨道参数只改变已有蝴蝶的局部环绕，不重播、不重建粒子。

## 文件变更

- `src/engine/types.ts`：移除 `ButterflyDistribution` 和旧分布字段，增加花朵轨道字段及默认值。
- `src/components/ControlPanel.tsx`：移除分布模式选择，增加固定模式提示和轨道参数滑块。
- `src/engine/scene.ts`：将蝴蝶运动统一为围绕花头的可倾斜椭圆轨道，加入速度、呼吸、漂移和跟随计算。
- `src/styles.css`：增加固定模式提示的面板样式。
- `README.md` 与 `wiki_memory/`：同步当前唯一飞行模式和参数语义。

## 测试与验证

- `npm run build`：通过，TypeScript 和 Vite 生产构建成功。
- `git diff --check`：通过。
- 重点验证：完成态继续保留 420 只蝴蝶和 36 朵花，参数修改不触发重播，固定模式不再出现其他分布选项。
- 产物检查：未把 `node_modules`、`dist`、原始 MP4 或分析帧加入 Git。

## 结果与下一步

- 结果：蝴蝶飞行逻辑已收敛为每只蝴蝶围绕自己的花朵独立飞行，面板可以直接调节轨道形态。
- 远程同步：本次实现与记忆更新将在收尾提交后推送至 `origin/main`。
- 下一步：如需继续校准，可优先调整默认半径和轨道速度，并在 8 秒完成态观察花头周围的覆盖密度。
