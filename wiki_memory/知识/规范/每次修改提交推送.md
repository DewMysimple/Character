# 每次修改提交推送

## 一句话结论

本仓库默认把每次完成的修改作为一个可审计提交，并同步推送到 GitHub 远程仓库。

## 适用范围

适用于代码、样式、配置、README 和工程记忆文件的修改。

## 详细内容

完成修改后，Agent 应检查 diff，运行相关验证，更新任务日志，使用单一意图的提交信息提交，然后执行 `git push origin main`。提交和推送是交付闭环的两个不同状态：推送失败时只能报告本地提交完成。

## 常见问题或陷阱

- 不要把未完成的半成品和无关改动混入同一个提交。
- 不要提交访问令牌、用户凭据或大体积参考媒体。
- 不要使用强制推送覆盖远程历史，除非用户明确授权且已确认目标。
